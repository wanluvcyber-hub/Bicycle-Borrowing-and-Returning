## 3. ข้อจำกัดของระบบแจ้งเตือน (ต้องระบุ)
1. **เป็น local notification** เซิร์ฟเวอร์ยกเลิกจากระยะไกลไม่ได้ ถ้านิสิตคืนจักรยานแล้วแต่ไม่เปิดแอป อาจยังโดนเตือนตามเวลา (แก้ได้ด้วย push จริง/FCM ซึ่งเกินขอบเขตวิชา)
2. **เวลาเด้งอิงนาฬิกาเครื่อง** ถ้านิสิตตั้งเวลาผิด เตือนจะเด้งผิดตาม แต่สถานะ "เกินเวลา" ฝั่งป้อมรปภ.ตัดสินด้วยเวลาเซิร์ฟเวอร์
3. **ความตรงเวลาขึ้นกับสิทธิ์ exact alarm** ของ Android ถ้านิสิตไม่อนุญาต ระบบอาจเลื่อนเวลาเด้ง (โดยเฉพาะตอนเครื่องหลับ) แอปจะขอสิทธิ์ครั้งเดียวตอนยืม
4. ⬜ ผลวัดจริง: เวลาเด้งเลื่อนกี่นาทีบนเครื่อง ______ (กรอกหลังทดสอบบน emulator/มือถือ)
