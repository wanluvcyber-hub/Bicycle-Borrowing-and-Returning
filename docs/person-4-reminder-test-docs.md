## ส่วน 1 — แจ้งเตือนและสถานะเกินเวลา (process 4.0)

### สิ่งที่แผนกำหนด
- เตือนนิสิตตอน **20.30 น.** และ **20.50 น.** ก่อนกำหนดคืน 21.00 น. (30 และ 10 นาทีก่อน `due_at`) ยืมได้กี่ชั่วโมงก็ได้ แต่ต้องคืนภายใน 21.00 น. ของวันเดียวกัน
- เลยเวลาแล้วต้องขึ้นสถานะ **"เกินเวลา"** ทั้งในแอปนิสิตและโปรแกรมป้อมรปภ.
- นับจำนวนครั้งที่คืนสาย (**ฐานข้อมูลนับให้แล้วใน `return_bike`** คุณไม่ต้องทำ)

### ส่วนที่ทำเสร็จแล้ว / ที่ฐานข้อมูลทำให้
| เรื่อง | สถานะ |
|---|---|
| สถานะ `overdue` | `get_my_active_loan()` คำนวณจาก `due_at` ให้ทันทีที่เลยเวลา · `mark_overdue_loans()` เขียนลงตารางให้ป้อมรปภ.เห็น |
| `late_count`, `is_late` | `return_bike` ทำให้ตอนรับคืน |
| ตั้งเวลาให้ฐานข้อมูลเปลี่ยน `overdue` เอง | ทางเลือก ใช้ `pg_cron` ทุก 5 นาที (ดูท้ายหัวข้อ 6 ใน `001_init.sql`) ไม่ทำก็ได้ |

### สิ่งที่คุณต้องทำ
**ที่อยู่:** `lib/features/reminder/` · แพ็กเกจ `flutter_local_notifications`, `timezone`, `flutter_timezone` เติมไว้ใน `pubspec.yaml` และตั้งค่า Android (desugaring, สิทธิ์ POST_NOTIFICATIONS) ไว้แล้ว

- [x] **บริการแจ้งเตือน** (`data/`): เริ่มต้น plugin, ตั้ง timezone เป็นเวลาไทย, ขอสิทธิ์แจ้งเตือน (Android 13+ ต้องขอตอนรัน)
- [x] ฟังก์ชัน "ตั้งเตือนของรายการยืมนี้": รับ `due_at` แล้วตั้ง 2 อัน คือ `due_at − 30 นาที` และ `due_at − 10 นาที` (ถ้าเวลานั้นผ่านไปแล้วให้ข้าม)
- [x] ฟังก์ชัน "ยกเลิกเตือนทั้งหมด"
- [x] **ข้อตกลงกับคนที่ 2 (ตกลงในวันแรก):** คนที่ 2 จะเรียกฟังก์ชันตั้งเตือนของคุณทันทีหลัง `borrow_bike` สำเร็จ ตกลงชื่อ/พารามิเตอร์แล้วเขียนไว้ในไฟล์นี้ (หัวข้อด้านล่าง "ข้อตกลง") แล้วให้คนที่ 2 เป็นฝ่ายเรียก คุณไม่ต้องไปแก้โฟลเดอร์ของเขา
- [x] **ซิงก์กับเซิร์ฟเวอร์ตอนเปิดแอป:** เรียก `get_my_active_loan()` ถ้าได้ `null` (คืนแล้ว หรือไม่มีรายการ) → ยกเลิกเตือนที่ค้างอยู่ · ถ้ามีรายการ → ตั้งเตือนใหม่ให้ตรงกับ `due_at` (กันตั้งซ้ำ ใช้ id คงที่)
- [x] แถบ/ป้ายแจ้ง "เกินเวลา" ที่ฝั่งนิสิตและฝั่งป้อมรปภ.ใช้ร่วมกันได้ (ทำเป็น widget กลางใน `presentation/` ของคุณ แล้วแจ้งคนที่ 2 และ 3 มา import) ตกลงหน้าตากับคนที่ 1 เรื่องสี `AppColors.warn` _(ทำ widget แล้ว · ยังไม่ได้ตกลงสีกับคนที่ 1 และยังไม่ได้ให้คนที่ 3 นำไปใช้)_

### ข้อจำกัดที่ต้องรู้ และให้ทีมตัดสินใจ
- การเตือนเป็น **การแจ้งเตือนในเครื่อง (local notification)** เซิร์ฟเวอร์สั่งยกเลิกจากระยะไกลไม่ได้ ถ้านิสิตคืนจักรยานแล้วแต่ยังไม่เปิดแอป อาจยังโดนเตือน 20.30/20.50 อยู่ ทางแก้ที่ง่ายที่สุดคือยอมรับข้อนี้ในรายงาน หรือใช้ push จริง (FCM) ซึ่งใหญ่กว่าขอบเขตวิชาและต้องแก้เซิร์ฟเวอร์ ให้ตัดสินใจกันแล้วบันทึกผลที่นี่
- Android อาจเลื่อนเวลาแจ้งเตือนที่ไม่ใช้ exact alarm (ประหยัดแบตเตอรี่) ถ้าต้องการตรงเวลาเป๊ะ ต้องเพิ่มสิทธิ์ exact alarm ใน `AndroidManifest.xml` และขอสิทธิ์ตอนรัน เป็นการแก้ไฟล์ร่วม ต้อง **เปิด PR แยก แจ้งทีม และรัน `flutter build apk --debug` ผ่านก่อน merge**
- API ของ `flutter_local_notifications` เปลี่ยนตามเวอร์ชันบ่อย ให้ดูตัวอย่างในเอกสารของเวอร์ชันที่อยู่ใน `pubspec.lock` (ตอนสร้างโปรเจกต์คือ 22.x) อย่าก๊อปตัวอย่างเก่าจากอินเทอร์เน็ตมาตรงๆ
- ผมยังไม่ได้ทดสอบการแจ้งเตือนจริงบนเครื่อง (ทดสอบแค่ว่า build ผ่าน) ต้องลองบนมือถือจริงหรือ emulator และเช็กว่าตั้ง timezone ถูก

### ข้อตกลงกับคนที่ 2 (เติมให้ครบในวันแรก)
```
ชื่อฟังก์ชันตั้งเตือน : ReminderService.instance.scheduleForLoan(...)
                        (หรือ context.read<ReminderProvider>().startLoan(activeLoan) ซึ่งเรียกอันแรกให้ และอัปเดตหน้าจอทันที)
พารามิเตอร์            : bikeNo (String), dueAt (DateTime จาก borrow_bike)  ห้ามส่งรหัสล็อก
ฟังก์ชันยกเลิก         : ReminderService.instance.cancelAll()  (หรือ ReminderProvider.clear() ตอนออกจากระบบ)
คนที่ 2 เรียกที่จุดไหน : หลัง borrow_bike สำเร็จ
หน้าหลักนิสิต          : ครอบด้วย ReminderLifecycle (ซิงก์ตอนเปิด/กลับจากพื้นหลัง)
                        แล้วโชว์ LoanCountdownCard(bikeNo, borrowedAt, dueAt)
ฝั่งป้อมรปภ.            : OverdueBanner(dueAt: ...) เมื่อ isOverdueAt(now)
```

**ตารางเตือนที่ตัดสินใจแล้ว:** 2 ครั้ง คือ 30 และ 10 นาทีก่อน `due_at` (= 20.30 และ 20.50 น. ตรงตามแผน) เตือนครั้งที่ 2 เป็นเตือนด่วน (เสียงแรงขึ้น) · ที่เพิ่มจากแผนคือ (1) เด้ง "เกินเวลา" ตอนถึง `due_at` (2) แถบนับถอยหลังค้างในแถบแจ้งเตือนตลอดช่วงที่ยืม ปิดแอปแล้วก็ยังเห็น · ถ้าซิงก์แล้วพบว่าเกินเวลาไปแล้ว จะแสดงสถานะ "เกินเวลา" แบบเงียบ ไม่เด้งเสียงซ้ำ
**เวลา:** ข้อความเตือนแสดงเวลาไทย (UTC+7) เสมอ ไม่ขึ้นกับโซนเวลาในมือถือ · การเตือนอิงนาฬิกาเครื่อง (ถ้าเครื่องตั้งเวลาผิด เตือนจะเด้งผิดตาม · สถานะเกินเวลาฝั่งป้อมรปภ.ตัดสินด้วยเวลาเซิร์ฟเวอร์ จึงไม่ได้รับผลกระทบ) ให้บันทึกในรายงาน
**exact alarm:** `ReminderProvider.startLoan` จะเปิดหน้าตั้งค่าให้ผู้ใช้อนุญาต exact alarm ถ้ายังไม่ได้อนุญาต (ถามครั้งเดียวต่อการเปิดแอป) เพราะยืมเช้า เตือน 20.50 ตั้งล่วงหน้าหลายชั่วโมง ถ้าไม่อนุญาต ระบบ (โหมด Doze) อาจเลื่อนเวลาเด้งจนเลย 21.00 น.
**Android:** เพิ่มใน `AndroidManifest.xml` แล้ว: `SCHEDULE_EXACT_ALARM`, `RECEIVE_BOOT_COMPLETED` และ receiver 2 ตัวของ plugin (ไม่มี receiver แจ้งเตือนที่ตั้งเวลาไว้จะไม่เด้งเลย) ไฟล์ร่วม ต้องเปิด PR แยก
